# software stack

## window manager

glazewm

responsibilities:
- tiling
- workspace management
- app routing
- title-bar removal
- gaps and window behavior

## status bar

yasb

status:
- existing setup
- do not modify from this repo unless explicitly decided later

## terminal

windows terminal

target:
- dark
- translucent
- wallpaper visible
- no heavy acrylic blur
- go mono nerd font 12

## shell

powershell 7

the shell should stay clean and fast.

## launcher

flow launcher

target:
- fast app launching
- minimal visual noise
- keyboard-first workflow

## browsers

chrome belongs on main by default.

fullscreen can be used when a clean browser surface is wanted.

## development

vs code:
- normal tiling
- code workspace

visual studio:
- normal tiling by default
- code workspace

roblox studio:
- roblox workspace
- give it enough space for its editor layout
