# wallpaper

## current

remilia scarlet / touhou gothic wallpaper.

display:
- 1920x1080

the chosen wallpaper is an existing high-resolution image. this project does not generate or upscale the wallpaper.

## rule

the wallpaper is part of the desktop composition.

do not:
- crop it unnecessarily
- place giant widgets over important artwork
- redesign the desktop around a different aspect ratio
- add a fake wallpaper recreation

## terminal relationship

terminal transparency should let a subtle amount of the wallpaper remain visible behind the terminal while preserving readability.
