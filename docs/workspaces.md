# workspace design

## main

general desktop.

primary home for:
- chrome
- normal daily apps
- quick browsing

shortcut:
- alt+1

## code

development workspace.

primary apps:
- vs code
- visual studio
- terminal

shortcut:
- alt+2

visual studio should participate in normal tiling unless a specific workflow proves that floating is better.

## roblox

roblox development.

primary app:
- roblox studio

shortcut:
- alt+3

## lain

lain development / ai workspace.

shortcut:
- alt+4

## media

music, media, reference, or other visual work.

shortcut:
- alt+5

## 6-9

reserved for future workflows.

## movement

alt+shift+1..9 moves the focused window to the corresponding workspace.

workspace names are preferred over numeric targets for the named workspaces.

## automatic routing

current intended routes:

- chrome → main
- vscode / code → code
- visual studio / devenv → code
- roblox studio / robloxstudiobeta → roblox

automatic rules should only be added when the process name has been verified.
