# visual direction

## overall

dark anime / gothic / cyberpunk windows setup with a remilia scarlet influence.

the goal is not to make every element scream touhou. the reference should come through in the palette, wallpaper, atmosphere, typography, and small details.

## visual hierarchy

1. wallpaper
2. workspace structure
3. top bar
4. application surfaces
5. small accents

nothing should compete with the wallpaper.

## palette direction

- near-black base
- charcoal surfaces
- deep crimson
- dark red
- muted magenta
- pale lavender / cool gray for readable text

avoid bright default windows colors.

## geometry

- tight gaps
- square or nearly-square surfaces
- minimal borders
- no giant rounded cards
- no excessive padding
- no unnecessary title bars

## transparency

transparency should reveal the wallpaper without making text hard to read.

current terminal target:
- non-acrylic
- roughly 84% opacity
- dark background

## typography

prefer compact monospace fonts for terminals and technical surfaces.

current terminal font:
- go mono nerd font
- 12pt

## personality

the setup should feel intentional without looking like a themed desktop pack.

avoid:
- giant anime logos
- fake lore text everywhere
- excessive widgets
- huge clocks
- noisy gradients
- unnecessary animations
